# Weekly Task — Peta Pekerjaan per Pertemuan

Pekerjaan Creativo disusun mengikuti pertemuan kuliah **Pemrograman Mobile**. File aplikasi tetap di tempatnya (`src/`, `supabase/`) supaya aplikasi tetap berjalan; folder `week-N` di sini menunjukkan **apa yang dikerjakan di setiap week, file mana, dan oleh siapa**, sesuai riwayat git asli.

| Week | Topik | Peta | Milestone | Kode |
|---|---|---|---|---|
| 1 | Kickoff — Define Your App | [week-1](week-1/README.md) | [Week 1](https://github.com/DevJamHub/Creativo/milestone/3?closed=1) | [`week-1`](https://github.com/DevJamHub/Creativo/tree/week-1) |
| 2 | Sprint 01 — Mobile Interface (React Native + Expo) | [week-2](week-2/README.md) | [Week 2](https://github.com/DevJamHub/Creativo/milestone/4?closed=1) | [`week-2`](https://github.com/DevJamHub/Creativo/tree/week-2) |
| 3 | Sprint 02 — Authentication & Secure Storage | [week-3](week-3/README.md) | [Week 3](https://github.com/DevJamHub/Creativo/milestone/5?closed=1) | [`week-3`](https://github.com/DevJamHub/Creativo/tree/week-3) |
| 4 | Sprint 03 — Data Modeling & RESTful API | [week-4](week-4/README.md) | [Week 4](https://github.com/DevJamHub/Creativo/milestone/6) | [`week-4`](https://github.com/DevJamHub/Creativo/tree/week-4) |
| 5 | Sprint 04 — Secure API & Token Authentication | [week-5](week-5/README.md) | [Week 5](https://github.com/DevJamHub/Creativo/milestone/7) | [`week-5`](https://github.com/DevJamHub/Creativo/tree/week-5) |

Week berikutnya ditambahkan setiap pertemuan selesai: milestone `Week N`, label `week-N`, issue tugas `[Week N] …`, folder `week-N/`, dan tag `week-N`.
